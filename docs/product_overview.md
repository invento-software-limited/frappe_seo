# Frappe SEO

**Frappe SEO** is the ultimate all-in-one SEO suite built for the Frappe framework. It transforms your Frappe site into a search engine powerhouse with automated metadata, real-time audits, Schema.org markup, dynamic XML sitemaps, and premium social sharing capabilities.

---

## Target Audience

- **Website Administrators** managing Frappe/ERPNext websites who want better search rankings
- **Content Managers** publishing blog posts, web pages, and Builder pages — all SEO-optimised automatically
- **Marketing Teams** who need consistent Open Graph and Twitter card presentation for social sharing
- **Frappe Developers** building customer-facing websites with deep SEO control

---

## Key Features

### 🤖 Intelligent Automation
- **Auto-Branding**: Automatically appends your Site Name with custom separators (`|`, `-`, etc.) to every page title
- **Smart Descriptions**: Extracts meaningful content from pages to create perfect meta descriptions
- **Keyphrase Extraction**: Suggests relevant focus keywords based on page titles
- **Automatic Social Cards**: Generates Open Graph (Facebook/LinkedIn) and Twitter cards instantly

### 📊 Real-Time SEO Analysis
- **Live Audits**: Instant feedback on title length, description density, and focus keyphrase usage
- **Builder Integration**: Deep support for Frappe Builder — extracts content from block layouts
- **Content Scoring**: Numeric SEO health score (0–100%) for every page and blog post
- **SEO Health Dashboard**: Donut charts showing system-wide SEO health with quick-access shortcuts

### 🌐 Advanced Technical SEO
- **Schema.org Graph**: Automatically injects JSON-LD markup (WebPage, Article, Organization, etc.) for rich search results
- **XML Sitemaps**: Dynamic, automated sitemap generation to help search engines crawl efficiently
- **Robots Control**: Easy `noindex` and `nofollow` management per page with a simple checkbox
- **Canonical URL Overrides**: Prevent duplicate content issues with custom canonical URLs

### 📈 SEO Dashboard
- **SEO Health Workspace**: Donut chart breakdown showing healthy, warning, and critical pages
- **One-Click Optimise**: Quick-access links to edit Web Pages, Blog Posts, and Builder Pages
- **System-Wide View**: See SEO health across your entire Frappe site at a glance
