# 🚀 Frappe SEO: The Ultimate Search Engine Optimizer

Experience the most powerful, all-in-one SEO suite ever built for the Frappe framework. **Frappe SEO** transforms your site into a search engine powerhouse with automated metadata, real-time audits, and premium social sharing capabilities.

---

## ✨ Premium Features

### 🤖 Intelligent Automation
*   **Auto-Branding**: Automatically appends your Site Name with custom separators (like `|` or `-`) to every page.
*   **Smart Descriptions**: Automatically extracts the most meaningful content from your pages to create perfect meta descriptions.
*   **Keyphrase Extraction**: Suggests relevant focus keywords based on your page titles.
*   **Automatic Social Cards**: Generates beautiful Open Graph (Facebook/LinkedIn) and Twitter cards instantly.

### 📊 Real-Time SEO Analysis
*   **Live Audits**: Instant feedback on title length, description density, and focus keyphrase usage.
*   **Builder Integration**: Deep support for **Frappe Builder**, extracting content directly from your block layouts.
*   **Content Scoring**: Get a numeric SEO health score (0-100%) for every page and blog post.

### 🌐 Advanced Technical SEO
*   **Schema.org Graph**: Automatically injects JSON-LD markup (WebPage, Article, Organization, etc.) for rich search results.
*   **XML Sitemaps**: Dynamic, automated sitemap generation to help search engines crawl your site efficiently.
*   **Robots Control**: Easily manage `noindex` and `nofollow` tags per page with a simple checkbox.
*   **Canonical URL Overrides**: Prevent duplicate content issues with easy canonical URL management.

### 📈 SEO Dashboard
*   **Real-Time Analytics**: A stunning workspace dashboard with donut charts showing your system-wide SEO health.
*   **Quick Access**: One-click shortcuts to optimize Web Pages, Blog Posts, and Builder Pages.

## 🛠️ Installation

1.  **Get the app**:
    ```bash
    bench get-app https://github.com/your-repo/frappe_seo
    ```
2.  **Install the app**:
    ```bash
    bench --site yoursite.local install-app frappe_seo
    ```
3.  **Run the Setup Wizard**:
    Navigate to **SEO Optimizer** in your Desk and complete the 2-minute onboarding to initialize your settings.
