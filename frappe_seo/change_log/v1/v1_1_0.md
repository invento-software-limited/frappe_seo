## [1.1.0] - 2026-11-10

### ✨ Added
- Item DocType SEO integration: added dedicated `meta_title`, `meta_description`, and `meta_image` custom fields alongside the full SEO suite (`focus_keyphrase`, social OpenGraph/Twitter tags, canonical URL, and index/follow options).
- Real-time Desk SEO analysis and Google search preview on the Item form.
- Automated save-time SEO enrichment (`before_save` hook on `Item`) for branded titles, schema inference, and SEO score calculation.
- Dynamic Schema.org `Product` JSON-LD generation for items in `seo_engine.py`.
- Sitemap generation support in `sitemap.py` for published items under `/shop/<custom_route>`, while filtering out parameterized dynamic Builder Page paths (e.g., `shop/:route`).
- Auto-migration patch `frappe_seo.patches.v1_1.add_item_seo_fields` to automatically install custom fields on migrate.

### 🎨 Changed
- Bumped version to 1.1.0.
- Enhanced `seo_engine.py` context injection to respect item metadata on dynamic Builder pages and prevent template titles from overriding specific Item titles.
